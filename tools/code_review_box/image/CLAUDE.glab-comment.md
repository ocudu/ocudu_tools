
## GitLab comments

This box was started with GitLab comments enabled. You may post MR comments with `glab mr note <iid> -m "<body>"`, and
nothing else: no approving, merging, editing or closing MRs, no issues, no `glab api` writes. `git push` stays disabled.

- Every comment starts with the line `ocudu code-review-box says:`. A hook refuses notes without it.
- Post only what the task asks for. When in doubt, write it to `~/results` instead.
